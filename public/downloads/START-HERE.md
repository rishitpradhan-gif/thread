# Thread locally

Extract all files. Install Python 3.10+ if needed. Open a terminal in this folder and run `python3 serve.py` (Windows: `py -3 serve.py`). Open http://127.0.0.1:8000. Keep the terminal open; Ctrl+C stops it. Use --port 8001 if port 8000 is busy. No Node installation is needed for this prebuilt download. Export backups before clearing browser storage.
