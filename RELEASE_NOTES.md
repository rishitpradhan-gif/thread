# Thread v0.1.0 — student app and extension

A concept wall for connecting ideas across classes—with a reason for every link.

- `thread-local.zip`: a prebuilt local browser app. Extract, run `python3 serve.py` (`py -3 serve.py` on Windows), and open http://127.0.0.1:8000.
- `thread-extension.zip`: a complete unpacked Chrome/Edge desktop extension, including the workspace. Extract, enable Developer mode on the extensions page, then Load unpacked.

Neither download needs npm installation, an account, or an API key. Keep backups when changing devices or uninstalling. See README.md and INSTALL-EXTENSION.md for limits, privacy, and setup.
